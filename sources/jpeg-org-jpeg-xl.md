## Summary

Official JPEG committee overview for JPEG XL. It frames JPEG XL as ISO/IEC
18181 and describes goals, feature areas, intended use cases, and the structure
of the specification family.

## Key Claims

- JPEG XL is standardized as ISO/IEC 18181.
- The standard is described in parts covering the core coding system, file
  format, conformance testing, and reference software.
- The format is positioned for web distribution and professional photography.
- Highlighted features include lossy and lossless coding, support for legacy
  JPEG migration, high dynamic range, wide color gamut, animation, alpha,
  layers, thumbnails, and progressive decoding.
