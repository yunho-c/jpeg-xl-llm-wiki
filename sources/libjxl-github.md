## Summary

The libjxl repository is the reference implementation for JPEG XL. It is the
main source for implementation behavior, command-line tooling, APIs, examples,
tests, benchmark tools, licensing, and practical developer workflows.

## Key Claims

- The repository describes libjxl as the JPEG XL reference implementation.
- It provides command-line tools including common encode/decode entrypoints.
- It contains implementation documentation, examples, benchmark-related tools,
  and source code useful for validating technical behavior.
- Licensing and patent-grant information should be checked directly in this
  repository before being summarized elsewhere.
