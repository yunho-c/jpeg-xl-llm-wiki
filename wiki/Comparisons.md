# Comparisons

This page compares JPEG XL with adjacent image formats. Keep comparisons
evidence-backed and specific: compression ratio, decode speed, encode speed,
feature coverage, tooling, browser support, licensing, and migration behavior
are separate dimensions.

## Key Points

- JPEG XL should not be described as simply "better" or "worse" than another
  format without naming the metric and source.
- Compare against JPEG, PNG, WebP, AVIF, HEIC/HEIF, JPEG 2000, and JPEG XS.
- Separate technical capability from deployment reality. A format can be strong
  technically while weakly supported in key environments.

## Comparison Axes

- Lossy compression efficiency.
- Lossless compression efficiency.
- Decode speed and memory behavior.
- Encode speed and encoder maturity.
- HDR and wide-gamut support.
- Alpha, animation, layers, previews, and thumbnails.
- Browser and application support.
- Patent, licensing, and standardization status.
- Migration from existing JPEG content.
