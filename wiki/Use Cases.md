# Use Cases

JPEG XL has different value propositions depending on the workflow. This page
tracks practical use cases separately so evidence can be evaluated in context.

## Key Points

- Web delivery depends heavily on browser and CDN support.
- Photography and image archival depend more on fidelity, metadata, color, HDR,
  and reversible JPEG migration.
- Editing and production workflows depend on application support and reliable
  tooling, not only the format specification.

## Use Case Areas

- Web image delivery and responsive loading.
- Existing JPEG migration and storage reduction.
- Photography workflows and camera pipelines.
- HDR and wide-gamut image distribution.
- Archival and preservation.
- Image editing and layered workflows.
- Animation or lightweight sequence delivery.
- Scientific or technical images that need lossless coding.
