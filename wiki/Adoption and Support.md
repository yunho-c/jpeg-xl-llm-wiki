# Adoption and Support

JPEG XL support changes over time. This page must stay conservative and
date-stamped: browser, OS, application, CDN, and tooling claims should include
an access date and cite source cards.

## Key Points

- Treat support status as volatile. Always record the access date when updating
  this page.
- Browser support should be backed by platform status pages, release notes,
  compatibility tables, or implementation repositories.
- Distinguish between native viewing support, browser rendering support,
  command-line tooling support, library support, and production deployment
  support.

## Current Snapshot

As of 2026-06-26, this wiki has not yet completed a comprehensive support
survey. Initial source cards should cover official platform-status sources
before this page is used for decisions.

Known areas to fill:

- Safari and WebKit support.
- Firefox status and configuration behavior.
- Chromium and Chrome status history.
- Operating-system image framework support.
- Application support in image editors, viewers, and asset pipelines.
- CDN, storage, and image-processing service support.
